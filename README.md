# Sokoban Solver

A push-optimal Sokoban solver: it answers all 5 instances of a set in one run, solving each room separately with push-based A* (minimum-assignment Manhattan heuristic, dead-square and frozen-block pruning) and stitching the rooms together with walks through the hallway.
